# ZoidbergChain Beta Invite Message Templates

Use these as lightweight starting points for the first 3 to 5 beta testers. Replace any placeholder wording as needed, but do not include real invite codes in this document.

## Text message

Hi! You are invited to test the ZoidbergChain beta: https://zoidbergcoin.com/

Please start from the access gate, request access if you have not already been approved, and follow the in-app Beta Guide if you need help. If Email / Social Wallet is enabled on your deployment, you can use that path. Otherwise please use MetaMask. We are mainly testing access, wallet setup, content submission, originality voting, and feedback. Test ZOID has no real monetary value. If anything feels broken or confusing, please use the in-app Send Feedback button.

## Email

Subject: You are invited to the ZoidbergChain beta

Hi,

You are invited to test the controlled ZoidbergChain beta at https://zoidbergcoin.com/

What to test:

- requesting access or using your invite code
- connecting MetaMask or Email / Social Wallet when enabled
- binding or reconnecting your approved wallet
- submitting content
- voting on originality
- sending in-app feedback

Important reminders:

- use MetaMask unless the deployment also enables Email / Social Wallet
- if you are not approved yet, please request access from the gate first
- test ZOID has no real monetary value
- never share seed phrases or private keys
- content, votes, accounts, and balances may reset during testing

If anything is confusing or broken, please send feedback from inside the app so we can review it quickly.

Thank you for helping us test.

If something breaks or feels confusing, please use the in-app Send Feedback button and tell us what happened.
