# ZoidbergChain Beta Launch Checklist

Use this checklist before inviting the first outside testers.

## Core readiness

- [ ] GitHub Actions are passing
- [ ] live site is deployed at `https://zoidbergcoin.com`
- [ ] access gate is working
- [ ] admin dashboard is working at `/admin`
- [ ] health and ops dashboard are healthy
- [ ] feedback system is working
- [ ] allowlist and override request flow is working
- [ ] audit log is recording expected admin actions
- [ ] backup status has been verified

## Wallet and device checks

- [ ] MetaMask desktop flow checked
- [ ] MetaMask Mobile flow checked
- [ ] mobile browser path checked on at least one iPhone and one Android device if available
- [ ] returning approved-wallet login checked
- [ ] one-time invite flow checked end to end

## Beta messaging and guardrails

- [ ] controlled beta language is visible
- [ ] test ZOID no-value disclaimer is visible
- [ ] reset risk disclaimer is visible
- [ ] wallet safety warnings are visible
- [ ] no admin tools are exposed in the public user UI

## Tester rollout

- [ ] first 3 to 5 testers selected
- [ ] invite message sent
- [ ] operator is ready to review feedback after each tester session
- [ ] operator is ready to pause invites if a blocking issue appears
